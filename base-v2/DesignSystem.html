PREMATCH
Design System v1.0
01 — Overview overview
Dark-first. Stats as hero.
Prematch is a sports analytics app built for players who want to see their data in sharp focus. The design language is deliberately sparse — deep black surfaces, a single lime accent (#c8f135), and numbers that dominate every screen.
Accent — one colour only. #c8f135 lime.
Never introduce secondary accent colours.
Viewport — mobile 390px.
All layouts designed at iPhone 14 Pro width.
Typeface — Archivo (900 for stats, 700 for headings, 400 for body).
Tokens — always var(--token), never raw hex in component code.
Design principles
Numbers take visual priority over labels. Stats are presented at hero scale — the viewer reads the number before the label. Surfaces use three elevation levels: --pm-bg (page), --pm-surface (cards), --pm-surface-2 (inset panels). All colours flow from CSS custom properties — never hardcode hex values in component styling.

08 — Patterns patterns
8.1 useCountUp Hook
// Ease-out cubic count-up from 0 to target over duration ms. // Re-runs when target changes. function useCountUp(target, duration = 1400) { const [val, setVal] = React.useState(0); React.useEffect(() => { let raf; const start = performance.now(); const tick = (t) => { const p = Math.min(1, (t - start) / duration); setVal(target * (1 - Math.pow(1 - p, 3))); if (p < 1) raf = requestAnimationFrame(tick); }; raf = requestAnimationFrame(tick); return () => cancelAnimationFrame(raf); }, [target]); return val; } // Display: Math.round(val).toLocaleString('en-GB')
8.2 IntersectionObserver Trigger
Attach to the display element directly — not a wrapper with display:contents. The observer threshold must be 0.4 so the animation fires when the element is meaningfully visible.
const obs = new IntersectionObserver(([e]) => { if (e.isIntersecting) setVisible(true); }, { threshold: 0.4 }); obs.observe(ref.current); // Then pass visible ? target : 0 to useCountUp
8.3 Scroll-Reveal Nav
const onScroll = () => setScrolled(el.scrollTop > 160); el.addEventListener('scroll', onScroll, { passive: true }); // Apply background + backdropFilter + title opacity // based on scrolled state (transition 250ms)

09 — Dev Handoff Notes handoff
1
Font loading — Archivo is loaded from Google Fonts in colors_and_type.css. Do not duplicate the import. In React Native, use Inter as a fallback with the same weight mapping (400/500/600/700/800/900).
2
Token usage — Import colors_and_type.css at the page level. Use only var(--token) in all style declarations. The only exceptions are the three status colours (Win/Loss/Draw) defined as JS constants WIN_GREEN / LOSS_RED / DRAW_AMBER.
3
Number formatting — Always use font-variant-numeric: tabular-nums on stat numbers. Format as Math.round(val).toLocaleString('en-GB') (produces "24,300"). Never use .toFixed() for display values.
4
Phosphor Icons — Loaded via CDN script tag. Regular: <i className="ph ph-icon-name"/>. Duotone: <i className="ph-duotone ph-icon-name"/>. Size via fontSize, color via color.
5
Z-index layers — Sticky nav: 20 · Sticky tabs: 10 · Bottom tab bar: 5 · Cards: auto (isolation: isolate on CardShell).
6
Safe areas — Tab bar uses padding-bottom: env(safe-area-inset-bottom, 0px). Top nav uses padding-top: 54px to clear Dynamic Island / status bar on notched iPhones.
7
Scroll performance — All scroll listeners use { passive: true }. Never call preventDefault() in scroll handlers. This ensures native scroll momentum is preserved on iOS.
8
Animation performance — Bar/underline animations use height or width transitions. Count-up uses requestAnimationFrame loops, always cleaned up on unmount via the cleanup function returned from useEffect.
9
Screen dimensions — Design target: 390×844px (iPhone 14 Pro). --screen-w: 390px, --gutter: 20px. Card widths: SCREEN_W - SIDE_PAD * 2 - PEEK where PEEK = ~16px to show the next card edge.
10
Component isolation — Each screen (Base, PlayerProfile, PlayerStats) is a self-contained .jsx file mounted into #root. Shared utilities (useCountUp, icon components) are duplicated per file — there is no shared module system in the prototype.
11
Rank colour logic — Team rank: =1 → lime. League rank: =1 → lime, ≤3 → white weight 700, >3 → rgba(255,255,255,0.3) weight 500. Apply this logic consistently across all stat tables throughout the app.
12
Left-border accent card pattern — border-left: 3px solid var(--accent) + border: 1px solid #1e1e1e + background: #0f0f0f + border-radius: 10px — used exclusively for synthesized editorial overview callouts (Headline Card). Never apply this pattern on data cards or stat tables.
